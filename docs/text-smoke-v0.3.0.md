## 定位与下一步

简版Prompt的自然语言流程和JSON要求之间还存在缺口：正式review模板明确nextFacts至少1项，但简版入口未同样强调；简版报告仅给自然语言清单，没有完整SessionReport结构约束，而且“报告末尾版本戳”容易被模型放成非法JSON字段。引用文本本身可靠，但模型计算字符偏移不可靠。

下一步应先在免费回放中强化简版入口字段约束、区分JSON字段与版本说明、处理应用层引用元数据，不放松引用与事实证据红线。保留本次失败原始记录；修正后的新版本需要另行授权复测。本轮不再调用模型，也不声称质量标定、网页语音、真人麦克风、原生宿主或统计后台已通过。
