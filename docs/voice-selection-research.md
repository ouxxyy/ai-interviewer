# Qwen3.8 Realtime 中文面试官音色调研

检索日期：2026-09-28（Asia/Shanghai）  
研究对象：`qwen3.8-omni-flash-realtime`  
范围：公开资料调研；2026-09-28 已据此把代码默认音色切换为 `Maia`，未调用付费 API。

## 结论

**建议把 `Maia`（四月）作为下一轮首选试听音色。** 它不是“网上公认第一名”——目前没有找到可信、可复现、针对 `qwen3.8-omni-flash-realtime` 预置音色的真人感排行榜——而是现有证据下最适合“中文、专业、温和的经历面试官”的候选：

- 阿里当前官方音色表明确列出 `Maia`，支持中文普通话，并将其描述为“知性与温柔的碰撞”；它可通过 Realtime 会话的音色参数使用。
- Qwen 官方在线 Demo 源码把 `Maia`、`Serena`、`Theo Calm` 等归在“情感陪伴－治愈温暖”组；这只能说明官方的风格定位，不能替代真人感测评。
- 一份第三方百炼实践文章将 `Maia` 用于 educational content，而把 `Serena` 用于 meditation / soft narration。该经验与“面试教练需要知性、清晰、不过甜”的目标更吻合，但它讨论的是 Qwen TTS，不是本项目的 Realtime 链路，权重只能算辅助。
- 当前用户已经明确反馈 `Serena` “有点难听”。这是与本产品真实使用场景最贴近的一条主观证据，因此不应继续仅凭官方“温柔”标签保留它。

**男声备选：`Andre`（安德雷）。** 阿里官方描述直接包含“自然舒服、沉稳男生”，并列明支持中文普通话；若用户希望更像正式面试官而非女声教练，它比角色感较强的男声更值得排第二。

**低风险回退：`Katerina`。** 它已在本项目既有真实探测中成功，但官方定位为“御姐音色，韵律回味十足”，角色感较强，未必比 `Maia` 更耐听，只适合作为不新增运行兼容性风险的回退候选。

## 证据分层

### 1. 当前模型与 Realtime 可用性（官方，强证据）

阿里百炼当前文档把 `qwen3.8-omni-flash-realtime` 列为实时音视频对话的优先模型，支持流式音视频输入与文本、音频输出；官方音色表为该模型单列章节，说明通过 `session.audio.output.voice` 选择音色，默认值为 `Tina`，并列出 `Maia`、`Andre`、`Serena` 等 voice ID。官方文档还明确该模型支持 WebSocket、WebRTC、AOQ 三种接入方式。

来源：

- [阿里云百炼：Qwen-Omni 实时模型](https://help.aliyun.com/zh/model-studio/realtime)
- [阿里云百炼：音色列表](https://help.aliyun.com/zh/model-studio/omni-voice-list)
- [阿里云百炼：Realtime 模型接入方式](https://help.aliyun.com/zh/model-studio/omni-realtime-model-access)

官方页面给出的相关候选如下：

| 顺序 | voice ID | 官方音色名与描述 | 中文能力 | 对面试官场景的判断 |
| --- | --- | --- | --- | --- |
| 1 | `Maia` | 四月；“知性与温柔的碰撞” | 中文普通话 | 最接近“专业但不压迫”的教练型面试官 |
| 2 | `Andre` | 安德雷；“声音磁性，自然舒服、沉稳男生” | 中文普通话 | 最接近正式、沉稳的男面试官 |
| 3 | `Theo Calm` | 予安；强调理解与疗愈 | 中文普通话 | 温和，但可能偏心理陪伴，不够像面试官 |
| 4 | `Liora Mira` | 清欢；强调人间烟火的温柔 | 中文普通话 | 有亲和力，但专业感描述弱于 `Maia` |
| 5 | `Katerina` | 卡捷琳娜；御姐音色、韵律突出 | 中文普通话 | 成熟，但角色感偏强；本项目旧探测已成功 |

注：这里的“适合场景”是基于官方声音定位与产品角色作出的推断，不是官方排名。

### 2. 官方风格分组（官方仓库，辅助证据）

Qwen 官方 Hugging Face 在线 Demo 的源码把 `Maia`、`Serena`、`Theo Calm` 放在 `Healing & Warmth / 情感陪伴-治愈温暖` 分组；同时把 `Katerina`、`Ryan` 等放在游戏动漫配音分组。该分组支持“`Maia` 比强角色音更适合温和教练”的判断。

不过这份 Demo 是 Qwen3.5-Omni 在线演示，不是 `qwen3.8-omni-flash-realtime` 的独立听感评测，所以只用于理解官方人设，不能证明 3.8 下的实际真人感。

来源：[Qwen/Qwen3.5-Omni-Online-Demo：app.py](https://huggingface.co/spaces/Qwen/Qwen3.5-Omni-Online-Demo/blob/14710a9ca7aa613f49e27ac67bc39156398f8592/app.py)

### 3. 公开用户/开发者经验（非官方，弱证据）

- 一位第三方开发者写明其实际使用分工：`Serena` 更适合冥想和柔和旁白，`Maia` 更适合教育内容，`Andre` 更适合专业旁白。这与本项目的面试教练定位一致，但属于单一作者经验，且文章所讲的是 Qwen TTS，不是 Realtime。
- 一个第三方试听台用 `qwen3-tts-flash` 让不同音色朗读相同短句，并做响度归一，方便横向试听。它明确提醒：短句快照无法代表长对话的断句、疲劳感和实时模型更新后的表现。这是试听工具，不是评分榜。

来源：

- [Alibaba Cloud Full Stack：Bailian and DashScope](https://www.chenk.top/en/aliyun-fullstack/10-bailian-llm/)
- [Foreverse：阿里百炼等音色同句试听台](https://foreverse.app/zh/labs/voice-gallery)

**样本局限：**未找到足量、独立、同一台词、同一 Realtime 模型、盲测且公开原始数据的用户评价，不能写成“网上公认 `Maia` 最真人”。第三方 TTS 样本只能帮助判断声线底色，不能外推到 Realtime 的停顿、情绪响应、打断后语气连续性。

## 候选排除理由

| 候选 | 不作为首选的原因 |
| --- | --- |
| `Serena` | 当前用户已在真实产品里给出负面听感；第三方实践也更偏向柔和旁白/冥想，不是专业面试对话。 |
| `Tina` | 虽是当前官方默认，但“甜甜、暖暖”的定位偏甜，缺少面试官所需的克制与专业感证据。 |
| `Ryan` | 官方描述强调节奏、戏感、张力和“真实”，真人感线索强，但表演性太强，长时间面试可能喧宾夺主。 |
| `Mia` | 官方定位为温柔生活博主；第三方试听目录把它归为角色感，更像内容主播而非面试官。 |
| `Jennifer` / `Aiden` | 官方人设重心分别是美语电影感女声和美语男声；虽然支持中文普通话，但不是中文面试场景的优先选择。 |
| 方言音色（`Dylan`、`Sunny`、`Rocky` 等） | 方言或地域口音会改变产品定位，除非用户主动选择，否则不适合作为默认中文经历面试官。 |
| `Katerina` | 成熟度合适且本项目旧探测已通过，但“御姐/韵律”角色感较强，优先级低于中性的 `Maia`。 |
| `Theo Calm` | 温和度合适，但疗愈人设可能削弱面试追问的干练感。 |

## 与本项目现状的兼容性

- 项目的代码默认音色已从 `Serena` 切换为 `Maia`，并继续以 `session.updated` 回显做前置断言。
- `docs/t1r-acceptance.md` 记录的旧探测只证明当时 15 个候选可用，其中不含 `Maia` 和 `Andre`；阿里当前官方列表虽已明确支持它们，但**当前账号、地域、业务空间与项目协议实现下尚未实时验证**。
- 因此当前只能声称“代码默认值已切换”，不能声称“`Maia` 已实时通过且比 `Serena` 更好听”。实调时仍须新开连接、检查 `session.updated` 的实际生效值，并在首个 `response.create` 前完成音色断言。

## 建议的最小试听验收（后续、会产生真实调用费用）

先做 `Maia`、`Andre`、`Katerina` 三音色盲测，不需要扩大到 55 音。每个音色使用完全相同的六类短句：开场欢迎、经历主问题、事实追问、温和打断、证据不足反馈、下一题过渡。至少由 3 人独立按 1–5 分评价：

1. 真人感（机械感、断句、连读）；
2. 面试官专业感；
3. 亲和但不甜腻；
4. 连听 10 分钟的疲劳感；
5. 中文数字、英文缩写、岗位术语的发音；
6. 打断后恢复时的语气连续性。

上线验收门槛：虽然代码默认值已按用户选择切换，仍只有在当前账号真实返回 `session.updated.voice === "Maia"`，且盲测真人感与整体偏好均胜过 `Serena` 时，才能将新音色标为已验收；否则依次试 `Andre`、`Katerina`。

## 验证边界

- **已确认：**当前阿里官方文档列出 `Maia`、`Andre`、`Serena` 等为 `qwen3.8-omni-flash-realtime` 可配置音色；这些候选支持中文普通话；`Maia` 的官方风格定位最贴近知性温和的面试教练。
- **尚未确认：**没有调用当前账号的 Realtime API，没有听取本项目真实输出，没有验证 `Maia` / `Andre` 的 `session.updated` 回显、语速、停顿、打断连续性或 10 分钟疲劳感。
- **不能声称：**“`Maia` 是全网评价第一”或“已经比 `Serena` 更真人”。目前只能声称：**基于官方支持范围、官方风格定位、有限公开实践与当前用户反馈，`Maia` 是下一轮最值得优先试听的候选。**
