常见问题

没有百炼 API Key，能直接开始 AI 模拟面试吗？

不能直接开始在线训练。先配置你自己的阿里云百炼 API Key，再填写目标岗位 JD、真实经历和求职阶段。公开岗位练习页无需 Key 即可阅读；保存配置后才进入在线训练材料页。

AI 面试陪练要收费吗？

平台工具不收取使用费，开源代码采用 MIT 协议。百炼模型调用费用由你的阿里云账号承担，模型权限、额度与服务限制以百炼账号实际情况为准。

材料、录音和 API Key 保存在哪里？

在线版按访客隔离保存数据，API Key 在服务器加密存储，不写入浏览器本地存储或回显。材料与回答会发送给配置的百炼模型；历史和录音按你选择的开关保存，关闭开关不会删除已有记录。你可按场次删除记录。

中文模拟面试的点评依据是什么，能保证通过面试吗？

点评依据你确认后的回答，并对引用做定位校验。无法通过校验时会提示重试或暂无法评价；不会把题目、建议或简历中的未口述内容当成回答证据。练习不保证录用或涨薪。
