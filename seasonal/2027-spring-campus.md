# 2027 春招与实习经历深挖训练包

## 适用场景
针对校园招聘、暑期/日常实习投递中“只有一段短期实习或校园项目、害怕面试官连环追问细节”的求职者。

## 三组高频压力追问（供喂给 `ai-interviewer` 练习）

### 场景 1：实习经历里的“打杂 vs 独立贡献”核验
- **首问**：你在实习期间参与的这个项目里，哪一个具体模块或决策是由你本人主笔完成的？如果当时没有你，上线结果会有什么不同？
- **常见失分原话特征**：大量使用“我们团队做了……”“配合导师完成了……”，缺少个人动作主语。
- **追问方向**：导师给你的初始输入是什么？你在中间改过几版方案？哪一次修改是因为你发现了别人没注意到的边界问题？

### 场景 2：数据指标的口径核实
- **首问**：简历里提到“转化率提升 15%”，请说明分子、分母、观察窗口，以及怎么排除同期其他活动的干扰？
- **追问方向**：如果当时没有条件做严格 A/B 实验，你用了什么替代证据来验证改动有效？

### 场景 3：AI 工具辅助开发的边界追问
- **首问**：在这个项目里你使用了 Claude Code / Cursor 辅助开发或写文档，请挑一个 AI 生成结果出错但被你拦截修复的具体案例讲讲。
